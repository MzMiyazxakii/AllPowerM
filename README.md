# AllPowerM

Minecraft 1.20.1 Forge mod project.

## Development environment

- Minecraft: 1.20.1
- Forge: 47.4.28
- Java: 17
- GeckoLib: 4.8.5

## Build

Install JDK 17 and Gradle 8.8, then run:

```bash
gradle build
```

The mod JAR is created in `build/libs/`.

GeckoLib is declared as a required runtime dependency and initialized by the mod entry point.
